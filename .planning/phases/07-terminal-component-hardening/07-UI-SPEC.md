# Phase 7 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Phase Nature

This phase is a **pure internal refactoring**. No new UI surfaces, screens, or user-facing interactions are introduced. The visual output of the terminal component must be **byte-for-byte identical** before and after the changes. The design contract below documents the existing visual state that must be preserved, not new design decisions.

## Interaction Contract

### What Must Not Change (Preservation Rules)

These behaviors are locked — Phase 7 must not alter them:

1. Auto-scroll: when `autoScroll` is true, the `Code` element scrolls to bottom on `lines.length` change. The internal `codeRef` must remain functional for this `useEffect`.
2. Platform detection: `platformStyle` state switches between `macos` and `adwaita` chrome on mount. Unchanged.
3. Scroll position tracking: `handleScroll` sets `autoScroll` false when not at bottom, true when at bottom. Unchanged.
4. Font size variants: all five `TerminalFontSize` values render correct CSS class. Unchanged.
5. Animation frame display: `AnimatedTerminal` passes `lines={frames[currentFrame]}` — Terminal renders them. After Phase 7, the rendered output must be visually identical.

### What Changes (Internal Only)

1. `Terminal` becomes a `forwardRef` component — the forwarded ref points to the inner `Code` element (the `<code>` DOM node).
2. `useImperativeHandle(ref, () => codeRef.current!, [])` exposes the inner element without replacing `codeRef`.
3. Line `key` changes from `key={i + line}` to `key={i}` — React reuses DOM nodes across frames instead of recreating them. No visual change.

### Ref Type Contract

- Forwarded ref type: `React.ForwardedRef<HTMLElement>` (matches Ghostty's `forwardRef<HTMLElement, ...>` pattern)
- Internal ref type: `useRef<HTMLElement>(null)` — unchanged
- `useImperativeHandle` return: `codeRef.current!` — the raw `HTMLElement`
